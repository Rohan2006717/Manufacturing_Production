# Manufacturing Production Line Optimization

## Overview

This project simulates and analyzes a 30-day manufacturing production line consisting of five sequential workstations: Cutting, Machining, Assembly, Inspection, and Packing.

Python is used to generate production data, calculate manufacturing KPIs, identify the production bottleneck, and evaluate improvement scenarios. The analysis focuses on Overall Equipment Effectiveness (OEE), throughput, downtime, and capacity utilization.

An Excel workbook is also generated to organize the production data and present the analysis through a management-level dashboard.

---

## Objective

The objective of this project is to analyze a simulated manufacturing production line and identify opportunities for production improvement.

The project focuses on:

- Manufacturing performance analysis
- OEE calculation
- Downtime analysis
- Bottleneck identification
- Capacity utilization
- Throughput analysis
- Process improvement
- Before-vs-after optimization analysis

The project demonstrates how production data can be analyzed using Python and Excel to support manufacturing process improvement decisions.
